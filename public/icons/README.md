# Pharma Lab home link

`pharma-lab-home.svg` is the home icon supplied by the project owner from:
https://github.com/hellophong/medlens-frontend/blob/main/assets/home_100dp_48752C_FILL0_wght400_GRAD0_opsz48.svg

The original SVG geometry is unchanged. The navigation renders it as a CSS mask using `currentColor`, matching the Lexicon forest-green palette. The link is labeled “Back to Pharma Lab” and navigates to https://hellophong.github.io/pharma-lab/ in the same tab.
